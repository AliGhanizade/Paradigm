# رشد · مسیر رشد مهارت‌ها

سایتی ایستا (Static) برای پیش‌رفتن در مهارت‌های فنی — فعلاً با چهار دورهٔ کامل: **گولنگ، SQL، جاوااسکریپت و کوبرنتیز**. بدون فریم‌ورک، بدون سرور، بدون حساب کاربری؛ همهٔ پیشرفت‌ها در `localStorage` مرورگر خودت ذخیره می‌شود.

## امکانات

- **دو مسیر برای هر دوره**: اکادمیک (فهم عمیق مفاهیم) و حرفه‌ای/بیزینسی (ساختن چیزهای واقعی)
- **مرور کلی**: خلاصهٔ کلیدی همهٔ دوره‌ها در یک صفحه + برگهٔ تقلب کدها + نقشهٔ کامل درس‌ها
- **ویدیوهای یوتیوب** برای هر درس، به دو زبان فارسی و انگلیسی، با تیک «دیدم»
- **آزمون** چهارگزینه‌ای داخل درس‌ها با ذخیرهٔ پاسخ‌ها
- **حالت روشن/تیره/سیستم**، چهار پالت آماده + **انتخاب رنگ دلخواه** با color picker
- ردیابی پیشرفت درس‌ها و ادامه از جایی که رها کردی
- گردی گوشه‌ها قابل تنظیم؛ کاملاً واکنش‌گرا

## ساختار پروژه

```
index.html          ← پوستهٔ سایت (هدر، پنل تنظیمات، جای رندر)
css/style.css       ← همهٔ استایل‌ها
js/app.js           ← منطق: مسیریابی، صفحات، تنظیمات، پیشرفت
data/
  courses.json      ← فهرست دوره‌ها (هر دوره = یک خط)
  go.json           ← دادهٔ کامل دورهٔ گولنگ
  sql.json          ← دادهٔ کامل دورهٔ SQL
  js.json           ← دادهٔ کامل دورهٔ جاوااسکریپت
  k8s.json          ← دادهٔ کامل دورهٔ کوبرنتیز
```

## افزودن دورهٔ جدید (مثلاً آشپزی!)

1. یک فایل JSON با همان ساختار دوره‌های موجود بساز و در پوشهٔ `data/` بگذار (مثلاً `cooking.json`).
2. در `data/courses.json` یک خط به بخش `courses` اضافه کن:

```json
{ "id": "cooking", "file": "cooking.json" }
```

همین! صفحهٔ دوره، درس‌ها، آزمون‌ها، ویدیوها و بخش مرور کلی خودکار ساخته می‌شوند. آیکون‌های آماده در `js/app.js` (شیء `IC`) تعریف شده‌اند؛ اگر آیکون خاصی لازم داری فقط یک ورودی به همان شیء اضافه کن.

## تغییر اسم سایت

اسم سایت، شعار و همهٔ عنوان‌ها از `data/courses.json` خوانده می‌شود — برای تغییر اسم فقط این خط را عوض کن:

```json
"site": { "name": "اسم جدید", "tagline": "شعار جدید" }
```

## اجرای محلی

چون داده‌ها با `fetch` خوانده می‌شوند، فایل `index.html` را مستقیم باز نکن؛ یک وب‌سرور کوچک بالا بیاور:

```bash
# در ریشهٔ پروژه، هرکدام که نصب است:
python -m http.server 8080
npx serve .
```

بعد در مرورگر: `http://localhost:8080`

## انتشار روی GitHub Pages

```bash
git init
git add .
git commit -m "رشد — نسخهٔ اول"
git branch -M main
git remote add origin https://github.com/USERNAME/roshd.git
git push -u origin main
```

بعد در گیت‌هاب: **Settings → Pages → Source: Deploy from a branch → main / (root)** — چند دقیقه بعد سایت روی `https://USERNAME.github.io/roshd/` در دسترس است. (فایل `.nojekyll` از قبل هست تا پردازش Jekyll رد شود.)
